# 📝 WriteMate AI - Backend

Backend API cho dự án **WriteMate AI**, xây dựng bằng **Node.js + Express + MongoDB**.  
Hệ thống hỗ trợ **Authentication (JWT, Cookie)** và **User Management** với kiến trúc module hóa.

---

## 🚀 Công nghệ sử dụng

- [Node.js](https://nodejs.org/) + [Express.js](https://expressjs.com/) - Web framework
- [MongoDB](https://www.mongodb.com/) + [Mongoose](https://mongoosejs.com/) - Database
- [JWT](https://jwt.io/) - Xác thực người dùng
- [bcryptjs](https://www.npmjs.com/package/bcryptjs) - Hash mật khẩu
- Middleware bảo mật:
  - `helmet`, `hpp`, `cors`, `compression`, `express-rate-limit`, `csurf`

---

## 📌 Yêu cầu hệ thống

- Node.js >= 18
- MongoDB đang chạy local hoặc trên cloud (MongoDB Atlas)
- Postman / Thunder Client để test API
